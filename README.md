# 플레이리스트 프롬프트 키트

주제 한 줄로 AI 음악 생성 서비스(Suno)에 넣을 재료를 한 번에 만드는 도구입니다.

- 레퍼런스 링크를 분석해 **음악 스타일 프롬프트**를 뽑고
- 주제를 넣으면 **10곡의 제목·훅·가사**를 만들고
- **앨범 커버 · 배경 영상 프롬프트**와 **수노 입력내용**을 항목별로 정리해
- 전부 **복사 버튼** 하나로 가져갈 수 있게 합니다.

## 열어보기

이 페이지는 **비밀번호로 암호화**되어 있습니다. 비밀번호는 배포한 사람에게 받으세요.
저장소에 올라간 `index.html`에는 암호문만 들어 있어, 비밀번호 없이는 소스를 봐도 내용을 읽을 수 없습니다.

## 만드는 방식

이 페이지 자체는 AI를 직접 호출하지 않습니다. 각 버튼이 **완성된 프롬프트**를 띄워 주면,
그 프롬프트를 Claude나 ChatGPT에 붙여넣고 **받은 답을 페이지에 다시 붙여넣어** 결과를 채웁니다.
페이지 왼쪽 아래 `반영하기` 칸이 그 역할을 하며, 기획안·스타일·가사·커버/영상 어떤 답이든 알아서 제자리를 찾아갑니다.

## 기술 메모

- 의존성 없는 단일 HTML 파일 (글꼴만 Google Fonts)
- AES-256-GCM + PBKDF2-SHA256(310,000회)로 본문 암호화, 브라우저 WebCrypto로 복호화
- 라이트/다크 모드, 휴대폰 화면 대응
